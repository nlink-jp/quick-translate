- Menu bar resident app with popover translation panel

- OpenAI-compatible API integration (default: LM Studio)
- Automatic language detection (NSLinguisticTagger)
- Debounce + manual button translation triggers
- One-click copy of translated text
- Settings: API endpoint, model name, target language, debounce delay
- Glossary support (JSON file, system prompt injection)
